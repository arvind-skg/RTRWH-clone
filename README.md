# 🌧️ RTRWH Assessment System

## Roof Top Rainwater Harvesting & Artificial Recharge Potential Assessment Application

## 📌 Overview

RTRWH Assessment System is a smart application designed to perform on-spot assessment of rooftop rainwater harvesting potential and artificial recharge requirements.

The system calculates:
- Rainwater harvesting potential
- Storage tank capacity
- Recharge pit dimensions
- Estimated installation cost
- Suitable harvesting methods

---

## 🎯 Problem Statement

Manual assessment of rooftop rainwater harvesting systems requires time-consuming calculations and technical expertise.

This application simplifies the process by providing instant recommendations based on:
- Roof dimensions
- Rainfall data
- Soil type
- Available space
